# Сюжетные расширения мастер-промпта
Все пункты наследуют `3d-master-prompt.md`. Ни один из восьми отдельных файлов ещё не сгенерирован; это очередь после выбора направления.

1. Ассистент: одна панель диалога стыкуется с двумя упорядоченными карточками; метафора преобразования запроса в запись, не автономного агента.
2. Календарь: матовая плитка с простой сеткой и одной коралловой ячейкой; без случайных цифр и ошибочных дат.
3. Задачи: три одинаковые карточки в стопке, одна с рельефной галочкой; общий габарит с календарём.
4. Время: лаконичный циферблат с двумя стрелками, один коралловый сектор; символ времени записи, не тайм-трекер.
5. Разговор: две состыкованные прямоугольные реплики, одна стеклянная, одна матовая; без микрофона, поскольку запись имитируется.
6. Идеи: карточка-заметка, входящая в прозрачный держатель; это редакционная метафора, отдельный режим идей не подтверждён продуктом.
7. Связи: две карточки объединены одной короткой муфтой; означает общие записи чата и календаря, не внешние интеграции.
8. Фокус: выделенная коралловая карточка внутри спокойной рамки; редакционная метафора выделения, не реализованный Pomodoro.

Приоритет производства: 2, 3, 1. После их согласования — 4, 5, 7. Сюжеты 6 и 8 сначала уточнить на уровне продуктового смысла.
