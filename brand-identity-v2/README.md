# competence. / Brand identity v2
11.10.2026 · готов первый этап: аудит, три направления и визуальные концепции.

Открыть `interactive-brandbook/index.html` напрямую в браузере — обзор полностью локальный, без сборки и сетевых зависимостей. Для HTTP-просмотра из этой папки: `python3 -m http.server 4178 --bind 127.0.0.1`, затем http://127.0.0.1:4178/interactive-brandbook/ .

## Готово
- `research/brand-audit.md`: факты, источники, расхождения и предложения.
- `art-direction/directions.md`: три различных направления, оценка и ограничения.
- Три актуальных PNG-листа без electric lime, по четыре сцены на каждом; встроенный imagegen.
- `design-system/visual-identity-draft.md` и `tokens.json`: общая предварительная основа.
- Четыре документа генерации в `documentation/`, актуальные корректирующие промпты.
- Локальная страница сравнения в `interactive-brandbook/`: переключение направлений, изображения, типографика, источники и скачивание.

## Ещё не выполнено
Направление не выбрано. Финальный интерактивный брендбук, отдельная серия из восьми иконок, прозрачные экспорты, размеры 1024/2048 и полный набор шести готовых носителей не выдаются за завершённые. Сейчас представлены композиционные концепции и тексты применений. Рекомендуемый следующий этап: выбрать направление, затем изготовить и проверить три эталонных объекта.

Electric lime исключён по прямому решению заказчика. Исторические значения сохранены только в исследовании. Исходные сайт и продукт не изменены. Ничего не опубликовано.
