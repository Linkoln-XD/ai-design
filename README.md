# Ассистент — демонстрационный прототип

## Запуск

```sh
npm ci
npm run dev
```

Проверки: `npm test` и `npm run build`. Готовый статический сайт — папка `dist`.
Для локальной проверки сборки: `npm run preview`.

## Показ на телефоне без браузерных панелей

1. Соберите сайт: `npm run build`.
2. Разместите содержимое `dist` в корне HTTPS-сайта на статическом хостинге. Manifest, иконки и assets должны быть доступны без авторизации.
3. Откройте HTTPS-ссылку на телефоне.
4. iPhone: Safari → «Поделиться» → «На экран Домой»; включите «Открывать как веб-приложение», если настройка показана.
5. Android: Chrome → меню → «Установить приложение» / «Добавить на главный экран». Если браузер предлагает установку через приложение, кнопка также появится в разделе меню «На домашний экран».
6. Запускайте по новой иконке. Адресной строки не будет; системные часы, батарея и жестовая панель остаются.

`127.0.0.1` на телефоне указывает на сам телефон, а не на компьютер разработчика. HTTP по локальному IP не заменяет HTTPS для проверки возможностей PWA. Встроенный предпросмотр также не подтверждает установленный режим на телефоне.

## Показ в iOS Simulator на этом Mac

Домен для локального показа не нужен.

1. Запустите `npm run dev -- --host 127.0.0.1` и оставьте сервер работающим.
2. В Safari внутри Simulator откройте `http://127.0.0.1:5173/`.
3. Нажмите «Поделиться» → «На экран Домой», включите «Открывать как веб-приложение», если переключатель доступен, и добавьте иконку.
4. Откройте приложение с домашнего экрана. Обычная вкладка Safari сохранит панели браузера.
5. Если ранее добавленная иконка показывает пустой экран, сначала проверьте загрузку URL в Safari и заново добавьте сайт с этой страницы.

Сборка, тесты и размеры иконок проверены. Установленный режим в Simulator пока не подтверждён: проверка управления симулятором была прервана. Пуши и микрофон нужно проверять отдельно на физическом устройстве через HTTPS.

## Что реализовано

- Manifest со стабильным id, областью действия `/` и `display: standalone`.
- PNG-иконки 192/512, maskable-иконка и Apple touch icon.
- Метаданные Apple, safe-area и мобильная вёрстка.
- Установка через событие браузера, когда оно доступно; ручные инструкции в остальных случаях.
- История хранится локально в браузере. Не рассчитывайте на перенос истории из вкладки в установленное приложение.

Сайт рассчитан на размещение в корне домена. Для подпапки необходимо согласованно изменить Vite base, manifest id/start_url/scope и пути иконок/manifest.

## Границы текущей версии

Для загрузки нужен интернет. Service worker, офлайн-кэш, пуши и настоящая запись микрофона пока не реализованы. Голос и ответы остаются демонстрационными сценариями.

Дальнейшие этапы: service worker и управляемые обновления; серверные Web Push подписки и планировщик; запись микрофона по разрешению пользователя и серверное распознавание. Секреты API должны оставаться на сервере.

## Проверка перед встречей

- Установить на целевой телефон, закрыть вкладку и открыть с домашнего экрана.
- Проверить отсутствие адресной строки, клавиатуру, карусель, меню и запись демосценария.
- Повторно запустить приложение и убедиться в сохранении истории.
- Проверить доступность сети на месте показа.

## Календарь и задачи

На десктопе календарь расположен слева, ассистент справа. На телефоне используются вкладки «Чат» и «Мои планы»; в компактной сетке даты с записями отмечены цветными точками. Под календарём находится повестка выбранного дня.

- «Создать» добавляет задачу, встречу или напоминание. Для встречи обязательны дата и время.
- Нажатие на запись в повестке или общем списке открывает редактирование и удаление. Последнее удаление можно отменить кнопкой «Вернуть» до закрытия уведомления или перезагрузки.
- Флажок отмечает задачу/напоминание выполненным; повторное нажатие возвращает в работу.
- «Все записи» показывает всю историю с поиском и фильтрами: в работе, просрочено, без даты, готово. В календаре поиск ограничен выбранным днём.
- Записи чата и календаря используют одно локальное хранилище. Ассистент исключает выполненные задачи из новых ответов о планах, но может найти их поиском. Текст старых сообщений остаётся историей, а карточки отражают текущее состояние записей.
- Стрелки клавиатуры перемещают выбранную дату. «Сегодня» возвращает к текущему дню.

Это локальный планировщик прототипа: синхронизации с Google Calendar/Tasks, общих календарей, повторяющихся событий и перетаскивания пока нет.

Проверено: сборка, 16 тестов (включая високосный февраль и фильтрацию), создание/редактирование/выполнение/удаление/восстановление в браузере, сохранение после перезагрузки и появление записей из чата. Проверены мобильные ширины 320 и 390 px. Проверка новой версии на физическом телефоне не выполнялась.

## Уточнение основных UX-сценариев

- На широком экране компактный месяц и повестка стоят рядом. На телефоне сначала видна неделя выбранной даты; «Выбрать дату» раскрывает месяц.
- «Добавить задачу» и «Добавить встречу» в чате открывают форму создания. Новая запись появляется карточкой в разговоре; «Изменить» открывает редактор прямо из карточки.
- При редактировании в планах сохраняются поиск и фильтр. Если изменённая запись вышла за их пределы, сообщение о сохранении предлагает «Показать».
- Поиск постоянно показывает область; пустой поиск по дню позволяет перейти ко всем записям с тем же запросом.
- Просмотр планов и поиск не сбрасывают незавершённую встречу. Отсутствующие дату и время нужно уточнить; день больше не выбирается автоматически.
- При вводе текста основная кнопка справа — отправка, микрофон становится второстепенным. В форме сохранение справа, удаление отделено слева.

Проверено после изменений: 17 тестов и сборка; в браузере — создание через форму, изменение из чата, сохранение запроса поиска, расширение поиска на все дни, завершение встречи после просмотра планов, раскрытие месяца. Просмотрены размеры 1440×900, 390×844, 390×667, 320×667 и 390×360. Последний — проверка тесного окна, не настоящей экранной клавиатуры. Скриншоты: `artifacts/ux-desktop-after.jpg`, `artifacts/ux-mobile-after.jpg`.
